# HONOR

**Make the call. Keep your word.**

HONOR is a prediction game for friend groups, built on Solana. Friends predict how things turn out. When predictions close, everyone who played votes on what really happened. Whoever was wrong owes the challenge the group agreed on (for example 30 push-ups), uploads proof, and friends approve it. Keep your word and you rise through the ranks; dodge it and you sink to **FUFLO**.

No money is ever at stake. Points can't be bought, sold, sent or redeemed: the program has no instruction that moves them.

## Run the app

Needs **Node.js 20+**.

```bash
cd app
npm install
cp .env.example .env      # VITE_CLUSTER=devnet by default
npm run dev               # http://localhost:5173
```

Players connect Phantom, Solflare or Backpack (switched to devnet), or pick **Demo Wallet**: a built-in test-network wallet that lives in the browser, so anyone can try HONOR without installing anything. "Get test SOL for fees" at the bottom of the page requests devnet SOL for network fees.

The free public devnet server is rate-limited. For many players at once, set `VITE_RPC_URL` (for example a free Helius devnet URL) in `app/.env`, or as an environment variable on Netlify.

**Windows note:** if Smart App Control blocks Rollup's native module (`@rollup/rollup-win32-x64-msvc`), swap in the WebAssembly build:
`npm install rollup@npm:@rollup/wasm-node@<rollup version> --no-save`

### Put it online

Netlify builds the site from this repo using `netlify.toml`: **Add new site → Import an existing project → GitHub → this repo**, then deploy. No other settings are needed; the app uses `#/` links.

## Build and deploy the program (Solana Playground, no install needed)

1. Open <https://beta.solpg.io>, create a new **Anchor** project, and paste `programs/honor/src/lib.rs` into its `src/lib.rs`.
2. **Build & Deploy → Program ID → Import** the program keypair (`target/deploy/honor-keypair.json`, kept privately).
3. **Build**, then **Deploy** (or **Upgrade** for later versions). The first deploy costs about 3–4 devnet SOL.

The program compiles with both Anchor 0.29 (Playground) and 0.32. If you change instructions or accounts, update the spec in `app/scripts/gen-idl.cjs` and run `node scripts/gen-idl.cjs` in `app/`.

## How it works

### A round, step by step

1. **Ask the question.** A member creates a round: question, 2–4 options, the challenge, how the result is decided, and deadlines. These rules are written on-chain and can never be edited or cancelled. A group needs at least 2 members to start a round.
2. **Make your call.** Each member picks an option and how sure they are (0–100%). The banner shows the group's odds.
3. **The group votes on the result.** When calls close, everyone who made a call votes once on what actually happened. As soon as one answer has a majority of all players, the round is decided. Otherwise anyone can count the votes when the window ends (or once everyone has voted).
4. **No result** if the vote is tied, nobody voted, or fewer than 2 people played. Nobody owes anything.
5. **Settle.** Anyone can settle everyone's predictions, so the wrong side can't dodge by never clicking.
6. **Prove it.** The person who owes it picks their video or photo. The browser computes its SHA-256 fingerprint; only the fingerprint goes on-chain, plus an optional unlisted link. Up to 3 attempts.
7. **Friends review.** Two other members (one, in a 2-person group) must approve. Rejections send it back for another attempt before the deadline.
8. **Missed.** After the deadline with no proof, anyone can mark it missed. Proof nobody finished reviewing is decided 2 days after the deadline: it counts only if more friends approved than rejected. People can also **decline** (voluntary) or spend a **shield**.

**Result decided by:** *Group vote*, or *AI check (beta)*. AI checking is not built yet; AI-check rounds are decided by the group vote for now and show a Beta badge.

### Points

| Action | Prediction Points | Honor Points |
|---|---|---|
| Correct prediction | 10, +1 per 20% confidence (max +5) | – |
| Voting for the result the group agreed on | – | +2 |
| Reviewing someone's proof | – | +2 |
| Completing your challenge | – | +15 |
| Missing your challenge | – | −20 |
| Declining your challenge | – | −10 |
| Buying a shield (skips one challenge, no honor lost) | −50 (spendable balance only) | – |

### Ranks (from Honor Points)

| Rank | Honor Points |
|---|---|
| FUFLO | below 0 |
| Squire | 0+ |
| Knight | 50+ |
| Paladin | 150+ |
| Champion | 350+ |
| Grand Master | 750+ |

### Leaderboards

- **Global:** Most honorable, Least honorable, and Prediction points (all Prediction Points ever earned).
- **Group:** Honor and Prediction points earned inside the group.

### Groups

The admin shares an invite link (anyone with it can join) and can make a new one at any time. The admin can **remove** a group: nobody can join or start rounds any more, but every round, call and point stays on the record forever.

### Accounts on-chain

| Account | Address seeds | Holds |
|---|---|---|
| `Profile` | `profile, user` | first and last name, Prediction Points, Honor Points, record, streaks, shields |
| `Group` | `group, admin, n` | name, sha256(invite code), member and round counts, removed flag |
| `Membership` | `member, group, user` | Prediction and Honor Points earned in this group |
| `Round` | `round, group, n` | locked rules, calls and confidence per option, result votes, result |
| `Prediction` | `prediction, round, user` | call, confidence, result vote, challenge status, proof fingerprint, approvals |
| `ProofReview` | `review, prediction, reviewer, attempt` | one review per friend per proof attempt |

Chat, personal details and the proof videos themselves stay off-chain. The optional proof link **is** public, so the app tells people to use unlisted links.

## Known limits

- **Friends can collude** and approve a fake proof, or vote a false result. The fingerprint stops anyone swapping the video later, but it doesn't make a bad video good. The AI check is meant to help here.
- **Invite links** contain the code, so anyone with the link can join.
- **No notifications yet.** The app refreshes every 15 seconds while it's open.
